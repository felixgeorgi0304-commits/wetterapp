# Screenshots

Hier gehören zwei Bildschirmfotos der laufenden Anwendung hinein:

| Datei | Inhalt |
|---|---|
| `hell.png`   | Hauptfenster im hellen Design, mit geladenem Ort |
| `dunkel.png` | dasselbe Fenster nach einem Klick auf die Design-Umschaltung |

Aufnehmen mit `mvn javafx:run`, dann unter macOS `Umschalt + Cmd + 4`,
anschließend Leertaste und das Fenster anklicken – so wird nur das Fenster
mit Schatten aufgenommen.

Das README bindet beide Dateien bereits ein.
